# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

Static website for **ExpertTech Consulting LLC** (`www.experttechllc.com`), an AI consulting firm targeting small and mid-sized organizations. No framework, no build step, no package manager lock file — files are served directly.

## Local development

```bash
npx serve          # or: npx http-server
```

Open the printed `http://localhost:` URL. You can also open `index.html` directly from the filesystem for most pages, but `index.html` uses blob URLs so a server is preferred.

Alternatively, with [Caddy](https://caddyserver.com/) installed:
```bash
PORT=8080 caddy run
```
The `Caddyfile` maps `{path}.html` fallbacks, so `/case-healthcare` resolves to `case-healthcare.html`.

## Deployment

Merging to `main` triggers `.github/workflows/static.yml`, which deploys the entire repository root to GitHub Pages. No manual deploy step exists.

## Architecture: two distinct page types

### 1. `index.html` — bundled single file
`index.html` is a self-contained bundle generated by a custom bundler. All CSS, JS, and binary assets are base64-encoded inside `<script type="__bundler/manifest">` and `<script type="__bundler/template">` tags. At runtime the loader decodes them (with optional gzip decompression via `DecompressionStream`), creates blob URLs, patches the template, and replaces the DOM. **Do not hand-edit `index.html` as if it were a normal HTML file** — its content block is machine-generated. Edits to the site's main page need to be regenerated through the same bundler tool that produced it.

### 2. Case study pages — plain HTML
`case-healthcare.html`, `case-logistics.html`, `case-agentic-workflows.html` are regular HTML files. They share a consistent section structure:
- Hero banner with `background-image` pointing to `images/case-*-hero.jpg`
- Sections: Executive Summary → About the Client → The In-Depth Challenge → Technical Deep Dive → Quantifiable Results & ROI → Client Testimonial
- Footer with navigation, contact info, and copyright

All case study pages reference `professional.css` (shared stylesheet) and Inter from Google Fonts. **`professional.css` does not currently exist as a standalone file in the repository** — it needs to be created or extracted before the case study pages will render correctly outside a bundled context.

`404.html` and `404.css` handle the GitHub Pages 404 route.

## Images

All images live in `images/`. Each case study has three images:
- `case-{name}.jpg` — thumbnail/overview
- `case-{name}-hero.jpg` — full-width hero banner
- `case-{name}-architecture.jpg` — architecture diagram

`IMAGE_SHOPPING_LIST.md` describes the conceptual content for each image. `logo.svg` is the site's vector logo.
